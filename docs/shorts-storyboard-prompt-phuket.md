# Shorts Storyboard Prompt — ฉบับปรับสำหรับช่อง "Thai Local in Phuket"

> ดัดแปลงจากเทมเพลต "Shorts Commentary Editing Prompt" ให้เข้ากับแผนช่อง (ดู `youtube-channel-handoff.md`)
> หลักต่างจากต้นฉบับ: ใช้ฟุตเทจจริงที่ถ่ายเอง/สัมภาษณ์จริงเป็นหลัก ไม่ใช้ภาพ AI แทน B-Roll (กันนโยบาย inauthentic content)

---

## Master Prompt (คัดลอกไปใช้ได้ทันที)

```
คุณคือ Video Editor และ Content Strategist สำหรับ YouTube Shorts ภาษาอังกฤษ
ช่องของฉัน: คนไทยท้องถิ่นในภูเก็ต/พังงา พาฝรั่ง (US/UK/AU วัย 45+ ที่คิดจะเกษียณ ย้ายมาอยู่ หรือซื้อคอนโด) ดูชีวิตและราคาจริง
ภาษาอังกฤษของฉันไม่เก่ง ประโยคที่ฉันพูดต้องสั้น ไม่เกิน 8 คำ/ประโยค และใส่คำอ่านภาษาไทยกำกับ

งาน: แปลง [ฟุตเทจ/ทรานสคริปต์] ด้านล่าง ให้เป็นตาราง Storyboard ตัดต่อ ความยาว [30–45 / 45–60] วินาที

ข้อมูล:
- ประเภทคลิป: [ตัดจากสัมภาษณ์ / ถ่ายเองพาดูสถานที่ / เปรียบเทียบราคา]
- คลิปยาวต้นทางที่จะลิงก์ไป (Related video): [ชื่อคลิปยาว]
- โทน: จริงใจ ตรงไปตรงมา มีตัวเลขจริง ไม่ขายฝัน

ตารางต้องมีคอลัมน์:
1. Timestamp
2. Voiceover / คำพูด (ภาษาอังกฤษ + คำอ่านไทยถ้าเป็นบทของฉัน)
3. Footage: A-Roll (หน้าฉัน/หน้าแขก) หรือ B-Roll จริงที่ต้องไปถ่าย (ระบุช็อตให้ชัด เช่น "ป้ายราคาในตลาดราไวย์ ซูมใกล้")
4. Camera / Motion (Punch-in 1.2x, Jump cut, Whip pan — ทำได้ใน CapCut)
5. On-screen Text (คำโฮไลต์/ตัวเลข) + SFX/เพลง

กฎ:
- 0–2 วินาที: เปิดด้วยประโยคที่แรงที่สุดของแขก หรือตัวเลขที่น่าตกใจ (cold open) + ตัวเลขตัวใหญ่บนจอ
- เปลี่ยนภาพทุก 1.5–3 วินาที
- ห้ามแต่งราคา/ข้อเท็จจริง ถ้าไม่รู้ให้เว้นเป็น [ใส่ราคาจริง]
- ซับอังกฤษตัวใหญ่ทุกคำ อยู่กลางจอ ไม่โดนปุ่ม UI ขวา/ล่าง
- ปิดท้ายด้วยประโยคที่วนกลับไปต่อกับประโยคเปิด (loop) + ข้อความ "Full interview → Related video"
- ท้ายตาราง: บอกรายการช็อต B-Roll ที่ต้องไปถ่ายจริง (shot list) และ Title + 3 hashtags

[วางทรานสคริปต์หรือโน้ตฟุตเทจที่นี่]
```

## ตัวอย่าง Storyboard (คลิปถ่ายเอง: ราคาคนไทย vs ราคานักท่องเที่ยว · 35 วินาที)

> ตัวเลขในวงเล็บ [ ] ต้องไปเก็บราคาจริงก่อนถ่าย ห้ามเดา

| เวลา | คำพูด (EN / คำอ่าน) | ภาพ / Footage | Camera | Text & SFX |
|---|---|---|---|---|
| 0:00–0:02 **Hook** | "Tourists pay [X] baht. I pay [Y]." / ทัวริสต์ เพย์ ... ไอ เพย์ ... | A-Roll หน้าคุณ ถือจานอาหารริมทาง | Punch-in 1.2x ทันที | ตัวเลขใหญ่ `[X] vs [Y]` · SFX Whoosh |
| 0:02–0:06 Setup | "Same food. Same street." / เซม ฟู้ด เซม สตรีท | B-Roll ร้านโซนแพตอง → ร้านโซนท้องถิ่น | Whip pan เชื่อม 2 ร้าน | `PATONG` / `LOCAL STREET` |
| 0:06–0:14 Proof 1 | "Pad thai. Patong: [X]. Here: [Y]." | B-Roll ป้ายเมนูจริง 2 ร้าน | Zoom ช้าเข้าหาป้ายราคา | ตัวเลขเด้งขึ้น · SFX Pop |
| 0:14–0:22 Proof 2 | "Songthaew to Kata. Tourist: [X]. Local: [Y]." | B-Roll รถสองแถว | Jump cut 3 ช็อตเร็ว | `[X] → [Y]` · Cash register SFX |
| 0:22–0:30 Value | "The trick? Ask this in Thai." / เดอะ ทริก? อาสก์ ดิส อิน ไทย | A-Roll หน้าคุณ พูดประโยคไทยสั้นๆ | Punch-in ตอนพูดไทย | ประโยคไทย + คำแปล EN · เพลงหยุด (Hard stop) |
| 0:30–0:35 Loop | "Now you know why tourists pay..." | กลับมาที่จานอาหารภาพแรก | Cut ตรง ให้ต่อกับ 0:00 | `Full guide → Related video` |

**Shot list ที่ต้องไปถ่าย:** ป้ายเมนู 2 ร้าน (แพตอง/ท้องถิ่น), รถสองแถว, หน้าคุณถือจาน, ถนนแต่ละโซน 3 วิ
**Title:** `Thai Local Shows: Tourist Price vs Local Price in Phuket` · `#phuket #thailand #expatlife`

## Checklist ก่อน Export (รวมจากต้นฉบับ + ส่วนที่เพิ่ม)

- [ ] 2 วินาทีแรกมีตัวเลขหรือประโยคแรงที่สุด
- [ ] ซับใหญ่ อยู่กลางจอ ไม่ชนปุ่ม UI ขวาและด้านล่าง
- [ ] เสียงพูดชัดกว่าเพลง (เพลงต่ำกว่าเสียงพูดอย่างน้อย ~15–20 dB)
- [ ] ทุกตัวเลขเป็นราคาจริงที่เก็บมาเอง และใส่เดือน/ปีไว้
- [ ] แขกที่ปรากฏในคลิปเซ็นใบยินยอมแล้ว
- [ ] ผูก Related video ไปคลิปยาวแล้ว
- [ ] ไม่มีภาพ AI แทนสถานที่จริง ถ้ามีภาพสมจริงที่สร้างด้วย AI ต้องติ๊ก Altered/synthetic content
